# 반 랭킹 연결 방법 (선생님용, 10분)

랭킹 점수는 **선생님 구글 계정의 구글 시트**에 모입니다. 무료이고, 따로 서버를 관리하지 않아도 됩니다.

## 1. 시트와 스크립트 만들기

1. 구글 드라이브에서 **새 구글 스프레드시트**를 만듭니다. 이름은 `로봇 상자 공장 랭킹`처럼 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 💾 저장합니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 아래처럼 맞추고 **배포**를 누릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 처음 한 번은 권한을 물어봅니다. 내 계정을 고르고, "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동 → 허용**을 누릅니다. (선생님이 직접 만든 스크립트라서 나오는 안내입니다)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. 게임에 연결하기

복사한 주소를 Claude에게 알려 주면 `js/rank.js`의 `RANK_URL`에 넣고 푸시해 줍니다.
직접 고칠 때는 `js/rank.js`의 `export const RANK_URL = '';` 따옴표 안에 주소를 넣고, `index.html`의 버전을 +0.001 올려 푸시합니다.

## 시트에서 볼 수 있는 것

시트 탭은 처음 쓸 때 저절로 생깁니다.

| 탭 | 내용 |
|---|---|
| `players` | 별명·비밀번호(암호화되어 있어 선생님도 숫자는 못 봄) |
| `sessions` | 근무를 시작할 때 받은 일회용 근무표 |
| `scores` | 올라간 기록: 일차, 매출, 보낸 상자, 완벽한 상자, 최고 콤보, 만든 전개도, 출고 기록 |
| `rejected` | 거절된 기록과 이유 (조작 시도나 오류를 볼 수 있음) |

- **기록 지우기**: `scores`에서 그 줄을 지우면 랭킹에서 빠집니다.
- **비밀번호를 잊은 학생**: `players`에서 그 학생 줄을 지우면 같은 별명으로 새 비밀번호를 등록할 수 있습니다.
- **새 학기**: `players`, `sessions`, `scores`, `rejected` 탭을 지우거나 새 시트로 다시 만듭니다.

## 게임 자료를 바꿨을 때

`js/data.js`의 물건·근무일·값을 바꾸면 서버 계산표도 같아야 합니다.

1. `python tools/ranking/sync.py`를 실행합니다. (`Code.gs`의 표를 `data.js`와 같게 고쳐 줍니다)
2. 바뀐 `Code.gs`를 Apps Script에 다시 붙여 넣고 저장합니다.
3. **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 누릅니다. (주소는 그대로입니다)

## 점수 조작을 어떻게 막나요

게임이 패드 브라우저에서 돌아가는 한 완벽하게 막을 수는 없습니다. 대신 패드가 보낸 점수를 믿지 않고 서버가 다시 검사합니다.

- 근무를 시작할 때 서버가 **일회용 근무표**를 줍니다. 근무 시간이 끝나기 전 제출, 같은 근무표 두 번 제출, 남의 근무표는 거절합니다.
- 점수 대신 **출고 기록**(언제, 어떤 물건, 어떤 전개도, 실수 몇 번)을 받습니다. 서버가 물건 값표로 매출 최대치와 콤보, 완벽한 상자 수를 직접 계산합니다.
- 다음과 같은 기록은 거절합니다.
  - 그날 나오지 않는 물건이 있음
  - 그날 올 수 있는 주문 수보다 상자가 많음
  - 상자 사이 간격이 15초보다 짧음
  - 기록으로 계산한 최대치보다 매출이 많음
- 별명마다 **4자리 비밀번호**가 있어 남의 별명으로 올릴 수 없습니다.
- 랭킹은 반을 나누지 않고 모두 한 랭킹에서 겨룹니다. (시트의 `반` 칸에는 늘 `전체`가 들어갑니다)
- 게임 속 조작 통로(`window.__game`)는 점검 봇 주소(`?test=1`)에서만 열리고, 그 주소에서는 랭킹에 올라가지 않습니다.

그래도 이상한 기록이 보이면 `scores`의 출고 기록을 보고 지우면 됩니다.
