# 로봇 상자 공장 (5-2 5단원 직육면체)

물류 센터의 신입 엔지니어가 되어 상자를 분류·재단·포장하며 직육면체를 익히는 태블릿 웹게임. 정적 사이트(index.html)이고, three.js r187은 `vendor/`에 들어 있음.

## 근무일 (교과서 순서)

| 일차 | 작업장 | 배우는 것 |
|---|---|---|
| 1 | 입고 분류대 | 직육면체·정육면체 정의, 정육면체는 직육면체 |
| 2 | 포장 마감대 | 면 6, 모서리 12, 꼭짓점 8 (먼저 세고 가져오기) |
| 3 | 송장 도면실 | 겨냥도: 보이는 모서리 실선, 숨은 모서리 점선 |
| 4 | 로봇 집게 라인 | 평행한 면 3쌍(밑면), 옆면 4개(수직) |
| 5 | 골판지 재단대 | 정육면체 전개도 (접어 보기로 확인) |
| 6 | 테이프 이음대 | 접었을 때 겹치는 점·선분 |
| 7 | 골판지 재단대 | 직육면체 전개도 (조각 끌어 놓기) |
| 8 | 종합 주문 | 재단 → 집게 → 송장 |

## 구조

- `js/main.js`: 화면 흐름, 저장(localStorage), 소리, `VERSION` (고칠 때마다 +0.001)
- `js/levels.js`: 근무일·단계 자료
- `js/three-view.js`: 3D 상자(View, Box3D), 꼭짓점 이름 ㄱ~ㅇ 교과서 배치
- `js/net.js`: 전개도 접기 판정(정수 계산), 같은 모양 판별, 겹치는 점·선분, 3D 접기 애니메이션
- `js/stations/*.js`: 작업장 6종. 규약 `export default function run(stage, spec, ctx)` → Promise
- 출처: `credits.html`, `THIRD-PARTY-NOTICES.txt`
