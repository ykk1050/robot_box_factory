# 로봇 상자 공장 (5-2 5단원 직육면체)

택배 공장에서 주문을 받아 골판지로 상자를 만들고 트럭에 실어 보내는 3D 경영 게임. 트럭이 떠나기 전까지 주문을 처리해 매출 목표를 채우고, 번 돈으로 공장을 업그레이드한다. 정적 사이트(index.html)이고 three.js r187은 `vendor/`에 들어 있음.

## 주문 하나의 흐름과 배우는 것

기사(남·여 선택)가 공장 안을 걸어 다닌다. 바닥이나 기계를 톡 누르거나, 아래 "가는 곳" 버튼을 누르면 그곳까지 걸어간다. 고른 주문서(상자 그림)는 왼쪽 위에 늘 떠 있다.

| 단계 | 하는 일 | 배우는 것 |
|---|---|---|
| ✂️ 재단 (작업대) | 골판지에 손가락으로 끌어 면을 그린다 → 밑면과 평행한 면 하나만 열어 둔 채 접히고, 물건이 들어간 뒤 그 면이 닫힌다 | 전개도, 서로 평행한 면의 모양과 크기, 접었을 때 겹치는 모서리의 길이, 면 6개 |
| 🩹 테이프 출력기 | 길이와 개수를 넣어 테이프를 뽑는다 → 작업대에서 모서리 12개에 길이가 맞는 테이프를 붙인다 | 모서리 12개, 같은 길이 모서리 4개씩 |
| 🛡 포장재 선반 | 깨지기 쉬운 물건이면 보호대를 꼭짓점마다, 냉장 물건이면 보냉 은박을 면마다 붙인다 | 꼭짓점 8개, 면 6개 |
| 🏷 스티커 제작기 | 밑면 스티커(쌓는 면 표시)와 옆면 스티커(취급주의)를 만든다 → 상자가 굴러 넘어진 뒤 "밑면" 도장을 찾아 붙인다 | 밑면 2개(서로 평행), 옆면 4개(밑면과 수직) |
| 🚚 출고 | 검수를 통과하면 컨베이어로 트럭에 싣는다 | 빠르면 팁, 재료를 많이 만들면 재료 값 손해 |

## 물건 특성·특별 주문·가방

- 물건 18종. 새로 들어온 물건: 접이식 우산(1×1×6), 우유(2×4×2), 피자(5×1×5), 아이스크림(3×2×2), 블록 세트(6×2×3), 액자(4×5×1). 모두 재단기(18×13칸)에 전개도가 들어가는 크기로 골랐다.
- 🧊 냉장(우유·아이스크림·케이크): 포장재 선반에서 보냉 은박을 가져와 면 6개에 모두 붙인다 → 면 6개
- ⬆️ 이쪽이 위(우유·피자·화분·액자): 스티커 제작기에서 화살표 스티커를 만들어 옆면 4개에 붙인다. 밑면에 붙이면 틀림 → 밑면과 수직인 옆면
- 📐 겨냥도 주문: 주문서에 길이 숫자 대신 겨냥도(보이는 모서리 실선, 보이지 않는 모서리 3개 점선, 길이만 표시)만 나온다. 6일차는 모두 겨냥도 주문, 7일차부터는 30%. 팁 +300원
- 🎒 가방: 재료 한 개(테이프 1줄·스티커 1장·보호대 1개·은박 1장)가 한 칸, 처음 30칸, 상점의 큰 가방으로 50칸. 넘치면 기계가 만들어 주지 않는다
- 근무일: 5일차 "시원한 배송", 6일차 "겨냥도 주문"을 새로 넣었다. 7일차부터는 자동으로 만들어지는 날이 이어진다

## 조작 연습 (🎓)

시작 화면의 "🎓 조작 연습"(처음이면 반짝임, 1일차 안내 창에도 버튼)으로 시간 제한 없이 큐브 퍼즐 주문 하나를 13단계로 따라 한다. 단계마다 위쪽 안내 줄에 할 일이 나오고 눌러야 할 곳이 노랗게 깜빡이며, 실제로 그 조작을 하면 다음 단계로 넘어간다: 주문 쪽지 → 재단기에 끌어 그리기 → 톡 눌러 지우기 → 전개도 완성·재단("도와줘"로 십자 전개도) → 화면 끌어 둘러보기 → 상자 굴리기 → 테이프 출력기로 걷기 → 테이프 출력 → 스티커 제작기 → 스티커 만들기 → 작업대로 돌아오기 → 도구로 붙이기 → 출고. 연습에서 번 돈은 저장되지 않는다.

## 전개도 유형과 콤보 (📐)

- 정육면체의 전개도는 돌리거나 뒤집어 같은 것을 하나로 보면 11가지: 1-4-1형 6가지, 2-3-1형 3가지, 2-2-2형 1가지, 3-3형 1가지. (정사각형 6개짜리 모양 35가지 중 정확히 11가지만 정육면체로 접힌다는 것을 `analyzeNet`으로 전부 확인함)
- 직육면체의 전개도는 접는 선의 방향을 따라 면을 같은 크기의 정사각형으로 바꾸면 이 11가지 중 하나가 된다(어느 면이 어느 쪽으로 이어졌는지가 같으므로). 길이까지 따지면 직육면체 전개도의 가짓수는 더 많지만, 게임에서는 이 11가지 배치로 유형을 나눈다.
- 콤보: 출고한 상자의 전개도 유형이 지금 콤보에 아직 없는 유형이면 콤보가 1 늘고, 이미 있는 유형이면 1부터 다시 시작한다. 콤보 k(2 이상)에서 보너스 300×(k−1)원, 최대 1,500원. 금형으로 같은 전개도를 다시 쓰면 콤보가 끊긴다.
- 재단기의 "📐 유형" 버튼, 화면 위 콤보 칸, 시작 화면의 "📐 전개도 유형 11가지"에서 11가지 그림과 지금 콤보에 쓴 유형(주황), 지금까지 만들어 본 유형(초록)을 볼 수 있다(유형을 보는 동안 시간은 멈춤).

틀리면 겹친 면이 빨갛게 보이고, 상자가 작으면 물건이 튀어나오는 식으로 결과가 화면에 그대로 나타난다.

## 구조

- `index.html`: `window.BUILD` = 게임 버전 (고칠 때마다 여기 하나만 +0.001). 모든 파일 주소에 붙여 패드 캐시가 섞이지 않게 함
- `js/main.js`: 화면 흐름, 근무(주문·타이머·돈), 단계 진행, 상점, 저장
- `js/data.js`: 물건(깨지기 쉬움 표시), 손님, 근무일, 업그레이드, 재료 값
- `js/factory.js`: 3D 공장, 기사 걷기, 기계 3대, 접기·물건 넣기·테이프·보호대·스티커·굴리기·출고
- `js/cutter.js`: 재단기(골판지에 면 그리기)
- `js/net.js`: 전개도 접기 판정(정수 계산), 접기 장치, 접힌/잘린 모서리 판별
- `js/nettype.js`: 전개도 유형 11가지, 접은 전개도의 유형 찾기(`classifyNet`), 유형 그림
- `models/`: Polyfork 모델(CC BY 4.0) · `sounds/`: Kenney(CC0)
